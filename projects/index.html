Timing Fixing by Useful Skew

A clock-tree optimizer that fixes every setup and hold violation in the public test cases — while cutting clock-tree area by about 64%

Li-Cheng Tseng, Li Juin Tan, Yi Cheng Chen, Zhi Qian Xiao (equal contribution) · Advisor: Prof. Jai-Ming Lin

Our solution to Problem D (proposed by Realtek): fixing timing violations without touching the circuit logic, by deciding where to delay the clock. A two-stage greedy optimizer fully fixed setup and hold timing on all five public test cases and reduced clock-tree area by about 64%.

HardwareSecurityFPGA

RISC-V Instruction Extension for Post-Quantum Signatures

A customized RISC-V processor with SIMD instructions that makes SLH-DSA signatures about 5× faster on an FPGA

Undergraduate research project · 2026.06

陳彥定, 黃子洵, Li-Cheng Tseng, 蔡丞昕 · Advisor: Prof. Pei-Yin Chen

SLH-DSA is a hash-based post-quantum signature scheme that is slow on small IoT devices. Reproducing the RVSLH paper, we added SIMD instructions to a RISC-V core and ran it on an FPGA — about 5× faster signatures and up to 34× faster hashing. I built the FPGA system that connects the processor to the board and runs the software on it.

CV32E40P · Synopsys VCS · riscv32-unknown-elf-gcc · Vivado · Xilinx PYNQ-Z2
